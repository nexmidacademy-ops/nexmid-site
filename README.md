## À propos

NEXMID GROUP est un écosystème technologique et éducatif basé à Abomey-Calavi, Bénin.

Il regroupe quatre entités :

| Entité | Domaine |
|--------|---------|
| **NEXMID TECHNOLOGIES** | Maintenance informatique, dépannage, installation, optimisation, diagnostic, remplacement, nettoyage |
| **NEXMID SHOP** | Vente d'ordinateurs, composants, accessoires, logiciels |
| **NEXMID ACADEMY** | Formation informatique de A à Z |
| **NEXMID ENGLISH** | Anglais technique |
